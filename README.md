# ✅ Task Manager

A Task Management application built with React and REST APIs that helps users organize and track daily tasks efficiently.

---

## Features

### Authentication

- Register
- Login
- JWT Authentication

### Task Management

- Create Task
- Edit Task
- Delete Task
- Mark Completed
- View All Tasks

### Profile

- Update Profile
- Upload Profile Image

### UI

- Responsive Design
- Clean Interface
- Loading Indicators
- Toast Notifications

---

## Tech Stack

- React
- JavaScript
- Vite
- Axios
- REST API
- CSS

---

## Installation

```bash
git clone https://github.com/zaidshaikh5301/task-manager.git

cd task-manager

npm install

npm run dev
```
